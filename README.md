# Система совместной подготовки к занятиям

Консольное приложение для организации совместной подготовки студентов.

## Возможности
- добавление студентов;
- создание групп;
- добавление студентов в группы;
- создание тем занятий;
- создание задач для групп;
- отметка выполнения задач;
- отчет готовности группы.

## Структура проекта
- main.py - точка запуска;
- storage.py - загрузка и сохранение данных в JSON;
- utils.py - безопасный ввод данных;
- models/ - классы и функции предметной области;
- data/ - файлы данных;
- tests/ - автоматические тесты.

## Запуск программы
python main.py

## Запуск тестов
pytest -v

## Проверка качества кода
flake8

## Основные классы

### Student
Представляет студента системы.
- Атрибуты: `id`, `name`, `email`
- Методы: `__str__()`, `from_data()` (classmethod)

### Group
Представляет учебную группу.
- Атрибуты: `id`, `name`, `students`
- Методы: `add_student()`, `has_student()`, `__str__()`

### Topic
Представляет тему занятия.
- Атрибуты: `id`, `name`, `date`
- Методы: `__str__()`

### Task
Представляет задачу по теме для группы.
- Атрибуты: `id`, `topic`, `group`, `title`, `done`
- Методы: `complete()`, `status_text()` (staticmethod), `__str__()`

## Взаимодействие объектов
Объект `Task` хранит ссылки на объекты `Topic` и `Group`.
Расчёт готовности группы выполняется по задачам, привязанным к группе.

## Хранение данных
Данные хранятся в JSON-файлах в папке `data/`.
При загрузке данные преобразуются в объекты классов.
При сохранении объекты преобразуются обратно в словари.

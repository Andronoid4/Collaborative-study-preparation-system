## 📌 Назначение проекта
Автоматизация и организация процесса совместной подготовки студентов к учебным занятиям. Система предназначена для удобного распределения учебных задач, обмена материалами, координации действий внутри группы и контроля общего прогресса подготовки к семинарам и практическим работам.

## 👥 Целевая аудитория
* **Студенты** учебных групп (в частности, группы ЭФБО-18-24), которым необходимо кооперироваться для подготовки к занятиям.
* **Преподаватели и кураторы**, заинтересованные в мониторинге активности группы и распределении учебных нагрузок.

## 📖 Описание предметной области
Предметная область охватывает процесс организации учебного взаимодействия внутри студенческой группы. При подготовке к семинарским или практическим занятиям студентам необходимо изучать определенные темы, решать задачи и готовить доклады. 
Зачастую объем материала велик, и его эффективнее осваивать совместно. Система позволяет структурировать этот процесс: разбивать общие темы на подзадачи, распределять их между участниками группы, обмениваться найденными материалами, обсуждать сложные моменты и отслеживать готовность каждого студента к предстоящему занятию.

## 🧩 Основные сущности
* **Группа (Group)** — учебная группа, объединяющая студентов и преподавателей (например, ЭФБО-18-24).
* **Студент (Student)** — участник системы, имеющий свой профиль, роль и список назначенных задач.
* **Тема (Topic)** — раздел или предметная область, которую необходимо изучить к определенному занятию (привязана к дате).
* **Задача (Task)** — конкретное действие или вопрос в рамках темы (например, «подготовить презентацию», «решить задачу №5», «найти литературу»), назначенный одному или нескольким студентам.

## ⚙️ Основные функции
1. Регистрация, авторизация и управление профилями пользователей.
2. Создание учебных групп и приглашение в них участников.
3. Формирование расписания: добавление тем и привязка их к датам занятий.
4. Декомпозиция тем: создание задач внутри тем и их распределение между студентами.
5. Отслеживание статуса выполнения задач (например: *к выполнению*, *в работе*, *готово*, *требует проверки*).
6. Обмен файлами, ссылками и комментариями в рамках конкретных задач.
7. Формирование сводной информации (дашборда) по готовности группы к ближайшему занятию.

## 🚀 План развития проекта
Данный файл является частью индивидуального проекта и будет дополняться в последующих практических работах. Этапы развития:
1. **Проектирование базы данных:** создание концептуальной и логической моделей, ER-диаграммы, написание SQL-скриптов для создания БД.
2. **Разработка серверной части (Backend):** реализация бизнес-логики, создание REST API для взаимодействия с клиентом.
3. **Создание клиентской части (Frontend):** разработка пользовательского интерфейса для удобного взаимодействия с системой.
4. **Интеграция дополнительных модулей:** добавление системы уведомлений (например, Telegram-бот для напоминания о дедлайнах).
5. **Аналитика и геймификация:** внедрение модуля статистики успеваемости и рейтинга активности студентов внутри группы.
